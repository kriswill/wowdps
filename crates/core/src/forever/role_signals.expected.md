## Rules

- Membership is curated in `tools/extract/src/signalgen.rs` as `(name, kind)`; the
  client expands each name to its ids. An id joins when `SpellName` carries the
  name, `SpellClassOptions` puts it in a class's spell family, and the client
  shows its kind's mark: a taunt an ATTACK_ME effect or a MOD_TAUNT aura, a shield
  cast a `SpellEquippedItems` shield requirement, a form a MOD_SHAPESHIFT aura into
  the form of the same name, a heal a HEAL effect or a PERIODIC_HEAL aura; a
  mitigation cast the family alone, and a bear's own attack only where its
  `SpellShapeshift` row requires Bear Form or Dire Bear Form (`in Bear Form or …`).
  A name no id passes fails the build.
- A cast line writes the id the player cast, which for an older heal or taunt is
  often a parent whose effect is a dummy or a trigger, the mark sitting on its
  child. So a same-named id in the family also joins a taunt or a heal when the
  client ties it to an id already in: an effect of it triggers that id
  (`triggers N`), or its own description names it (`its text names N`), read to a
  fixpoint; never a rune's passive (an id with the OVERRIDE_ACTIONBAR_SPELLS aura),
  which carries the name and is never cast. A cast whose client data ties it to
  no such child (Earth Shield's, Prayer of Mending's) is not in: only its heal's
  id is, which a cast line never writes, so those casts count as no heal.
- The committed census `tools/role-signals-census.csv` (`tools/census-role-signals.sh
  <log>...`: every `SPELL_CAST_SUCCESS` a `Player-` guid wrote, counted per (id,
  name) per log) must show a player casting one of a name's ids, under that name,
  unless the entry carries a `census_exempt` reason, printed below in place of the
  counts (`exempt: …`).
- What a WAIVED entry's ids are known to be: each carries the name, the class family
  and the kind's mark, or a tie the client records to an id that does. What they
  are NOT known to be: the id a cast line writes. No committed log holds a player
  casting one, so a cast the client ties to nothing would be missed, and the first
  census to hold one settles it.
- The meter (CONTRACT.md R30) counts a player's casts of each kind and, for a form,
  the time its aura is on them, in each fight alone; the role solver weighs them
  with the fight's swings, healing and damage.
