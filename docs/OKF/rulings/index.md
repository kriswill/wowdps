# rulings

CONTRACT.md's binding rulings R1–R20 — what counts as damage, healing, absorbs, segments, pets, visits, taken, spans, support, shields — one doc per ruling, scaffolded from the rulings table.

## Concepts

* [R1 Damage](r1.md) - Row amount = event `amount + absorbed`; extra = overkill (≥0).
* [R10 Visits & Overall](r10.md) - Difficulty ≠ 0 zoning opens a visit (suspend/resume on zoning; keyed visits resume on map alone); CHALLENGE_MODE_START resets the visit; Σ = members merged, duration = Σ of member durations — except a keyed Σ runs on the KEY clock and reports the TIMED verdict vs par.
* [R11 Meaningful segments](r11.md) - A closed segment earns a list row only if: Encounter, non-empty enemy tally, player-damaged-player, or a player died.
* [R12 Timelines & markers](r12.md) - Per-guid 1s damage/heal grids + bounded curated item markers (class_spells vetoes the generous item table); all segment-local, never opening segments; Σ merges curves on the visit clock.
* [R13 Arena](r13.md) - ARENA_MATCH_START..END is an Encounter named from the last zone; verdict = home side (from match-local COMBATANT_INFO factions) vs winningTeam, worded WIN/LOSS; the post-END tail is unlisted `noise`; `enemy` rows split teams in arena segments only.
* [R14 Talent dataset & codec](r14.md) - `gen-talent-trees` builds a per-machine talents.json from the install's Trait DB2s; the mcp codec speaks import-string v2 from the dataset alone (no daemon); gated on a real string's byte-identical round-trip.
* [R15 Count views & labels](r15.md) - Interrupts drill: "{kicked} ({ability})"; CC drill: "{cc} ({victim})"; CC view counts a curated loss-of-control list (exactness not gated).
* [R16 Boss health](r16.md) - Inside an open raid-boss Encounter, the advanced block's health report for a hostile NPC (Creature-/Vehicle- guid) is a boss-health observation, tracked per NPC; the BOSS is the NPC with the largest max health seen (any NPC with at least half that is a boss too — councils — provided its creature id spawned once: an add pack is never a council), and `Segment::best_pct` = the lowest fraction among the bosses still standing, whole percent rounded down — a member that is down (under 0.1 %: the game parks a boss it will not let die yet at 1 HP) is progress, not the grade; 0 when every boss is down, and always 0 on a kill (ENCOUNTER_END success — a scripted death lands no 0/max report); never 0 for an add or a friendly guardian dying.
* [R17 Damage taken & mitigation](r17.md) - Every damage event whose destination is a player or pet (pets fold onto owners, R4) is recorded a second time on the DESTINATION as `View::Taken`: amount = R1's `amount + absorbed` (the log's amount is post-block, so blocked is NOT added — per segment Σ every actor's Damage by_target over friendly names = Σ Taken rows + Σ `stagger_ticked`, exactly), extra = absorbed, by-spell = taken by ability, by-target = taken by ATTACKER NAME (R5's pet-by-name precedent; never a guid).
* [R18 Aura spans with caster & target](r18.md) - A Buff `AuraApplied`/`AuraRefresh` on a player whose spell is in the CURATED, generator-validated role table (`ActiveMitigation` / `Defensive` / `External` / `SupportBuff` / `Cooldown`) opens a span keyed by TARGET with the CASTER as `src`; `AuraRemoved` closes the newest; a refresh/removal with no open span opens one at segment start; the close at segment end is read-time and kind-branched; spans capped (`SPAN_CAP`), the `uptime` rollup uncapped; `am_uptime_pct` = the UNION; `externals_given/received` count+ms; `support_uptime` per target.
* [R19 Support attribution](r19.md) - The six `*_SUPPORT` damage/heal families become `Event::Support` (pop the trailing supporter guid, dispatch on the base family with the spell prefix; amount = the buff's share); per player `given` / `received` / `targets`, raw-keyed and folded at read; passive gate only; `effective = damage − received + given` DERIVED, never stored, Σ effective = Σ damage; `Spec::support` is a flag only; `SPELL_ABSORBED_SUPPORT` → Other.
* [R2 Healing](r2.md) - Amount = effective (amount − overheal); extra = overheal.
* [R20 Shield ledger & absorb efficiency](r20.md) - A Buff `AuraApplied` / `AuraRefresh` / `AuraRemoved` on a friendly whose spell is in the GENERATED absorb-spell table (`core/src/absorb_spells.rs`: every spell with a `SpellEffect` row whose `EffectAura` is 69, SCHOOL_ABSORB) drives a SHIELD keyed `(raw target, spell id, raw caster)` — aura src = the absorber of `SPELL_ABSORBED`, universally (census: 0 mismatches across ~60 shield spells in both raid logs) — with the parser's trailing `absorb`: APPLIED = the initial size, REFRESH = the NEW RUNNING TOTAL (never a delta), REMOVED = what REMAINED.
* [R3 Absorb attribution](r3.md) - One source per direction: SPELL_ABSORBED → healing, the damage-event absorbed field → damage.
* [R4 Segment boundaries](r4.md) - ENCOUNTER_START opens (closing any open), END closes exactly (no grace window); other combat accrues to Trash, split after >60s quiet; every ZONE_CHANGE closes open Trash.
* [R5 Pets](r5.md) - Summoned units fold onto their owner — never separate meter rows; by-spell rows aggregate per pet NAME.
* [R6 Version seam](r6.md) - Mid-log COMBAT_LOG_VERSION: close the segment, reset the pet map, SUSPEND the visit (the re-fired ZONE_CHANGE resumes it).
* [R7 Duration](r7.md) - Encounters = START..END; Trash = first..last combat event.
* [R8 Class/spec inference](r8.md) - Inferred from a FIXED list of player-sourced spell events against the generated `class_spells` table; segment-local; COMBATANT_INFO overwrites and alone persists; never opens a segment.
* [R9 Deaths & recap](r9.md) - First-death order; per-player 32-event ring (damage w/o absorbed part + gains), drained at UNIT_DIED, latest death wins; recap newest-first with hp/gain; never opens a segment.
